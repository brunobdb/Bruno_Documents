# Archives / Arquivos

Esta pasta contém arquivos compactados, backups e outros arquivos arquivados.

This folder contains compressed files, backups, and other archived files.

## Tipos de Arquivo / File Types

- Arquivos compactados (.zip, .tar, .gz, .7z, .rar)
- Backups
- Imagens de disco (.iso)
- Outros arquivos arquivados / Other archived files

## Notas / Notes

⚠️ **Importante / Important**: 

- Arquivos grandes podem não ser adequados para o Git
- Considere usar Git LFS para arquivos grandes
- Mantenha backups em locais seguros

- Large files may not be suitable for Git
- Consider using Git LFS for large files
- Keep backups in safe locations
