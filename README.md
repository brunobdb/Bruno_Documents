# Bruno_Documents

Repositório para organização de pastas, scripts, arquivos, códigos e documentos de texto.

Repository for organizing folders, scripts, files, code, and text documents.

## 📁 Estrutura do Repositório / Repository Structure

```
Bruno_Documents/
├── scripts/        # Scripts de automação e utilidades / Automation and utility scripts
├── documents/      # Documentos de texto, PDFs, etc. / Text documents, PDFs, etc.
├── code/          # Código-fonte e projetos / Source code and projects
├── archives/      # Arquivos compactados e backups / Compressed files and backups
└── README.md      # Este arquivo / This file
```

Contains scripts for automation, utilities, and helper tools in various languages (Shell, Python, JavaScript, etc.).

Stores text documents, PDFs, spreadsheets, presentations, and other documentation formats.

Stores compressed files, backups, and other archived materials.

## 🚀 Como Usar / How to Use

1. Clone este repositório:
   ```bash
   git clone https://github.com/brunobdb/Bruno_Documents.git
   ```

2. Navegue até a pasta desejada:
   ```bash
   cd Bruno_Documents/scripts
   ```

3. Adicione seus arquivos nas pastas apropriadas

   Add your files to the appropriate folders

4. Commit e push suas alterações:
   ```bash
   git add .
   git commit -m "Descrição das mudanças"
   git push
   ```
